# TOOLS.md -- Default Tool Guidance

## Tool Rules

- Prefer primary sources and current repo state over memory.
- Read existing files and issue context before creating new structure or conventions.
- Use fast local search and focused reads first, then run the smallest useful verification step.
- Mutating Paperclip issue calls must include `X-Paperclip-Run-Id`.
- Use `para-memory-files` for durable memory, daily notes, and plan lookups when your role depends on memory.
- If a required tool, permission, or credential is missing, block the task explicitly instead of improvising.
